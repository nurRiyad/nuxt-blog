### Introduction

You can create a subdomain in Namecheap and point it to an app deployed on Vercel by adding the DNS record Vercel requests. The exact values may vary, so check the domain instructions in your Vercel project.

### Step 1: Add the subdomain in Vercel

Open your Vercel project, go to **Settings → Domains**, and add the subdomain you want to use, such as `app.example.com`. Vercel will show the DNS record needed to connect it.

### Step 2: Create the DNS record in Namecheap

Sign in to Namecheap and open **Domain List → Manage → Advanced DNS** for the domain. Add the record shown by Vercel. For a typical subdomain this is a CNAME record: set **Host** to the subdomain label (for example, `app`) and use the **Value** provided by Vercel.

### Step 3: Verify the connection

Return to the Domains page in Vercel. It will check the DNS configuration and show when the subdomain is connected. DNS updates can take time to propagate.

### Conclusion

Once the DNS record matches Vercel's instructions and has propagated, the subdomain should direct visitors to your app. If verification fails, compare the record in Namecheap with the values Vercel displays.
