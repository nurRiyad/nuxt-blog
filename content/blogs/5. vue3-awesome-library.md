### Introduction

Vue 3 has a broad ecosystem of libraries that can help with common application needs. Here are some options in a few categories. Review each project's documentation and maintenance status before choosing it for a new application.

### Core tools

- **Vue Router**: The official router for building navigable Vue applications.
- **Pinia**: A store library for sharing and managing application state.
- **VueUse**: A collection of Vue composition utilities.
- **Vitest**: A test runner designed to work with Vite-based projects.
- **Vue Macros**: A collection of experimental and proposed syntax extensions for Vue. Check compatibility and project activity before adopting it.

### UI libraries

UI libraries provide ready-made components and styling. Some options include:

- **Naive UI**: A Vue 3 component library with TypeScript support and theming options.
- **Vuetify**: A Material Design component framework for Vue.
- **Vuestic UI**: A Vue component library with tools for building interfaces and dashboards.

### Other useful libraries

- **VueFire**: Firebase bindings for Vue and Nuxt.
- **Vue I18n**: Internationalization support for Vue applications.
- **AutoAnimate**: Adds simple transitions to interfaces with minimal setup.
- **Vuelidate**: Model-based form validation for Vue.

### Conclusion

These libraries cover common needs, but the right choice depends on your project and its constraints. Check the current documentation, compatibility, and maintenance activity before adding a dependency.
